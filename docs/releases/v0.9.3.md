CLIPALKA 0.9.3 для Windows 10 и 11 (x64).

- На «Монтажном столе» последний клип и три недавние записи видны рядом. Под кадром расположены сохранение момента, ручная запись и микрофон с индикатором уровня.
- Разделы захвата, киноархива и настроек открываются из боковой панели. В архиве можно найти клип по названию, воспроизвести его и открыть его папку.
- Новый значок «Дубль» используется в приложении, трее и на ярлыках Windows.
- Кнопка «Свернуть» оставляет окно на панели задач. Крестик скрывает его в трей, пока буфер продолжает работать.
- Улучшен выбор активного окна Roblox в оконном режиме. Небольшое окно игры может сменить ошибочно выбранный источник. Game Network и ChatGPT исключены из автоматического выбора игры.

Для обновления завершите текущую запись и запустите **CLIPALKA-Setup.exe** поверх прежней установки. Клипы и настройки сохраняются. Для запуска без установки распакуйте **CLIPALKA-win-x64.zip**. Контрольные суммы обоих файлов находятся в **SHA256SUMS.txt**.
