# CLIPALKA 0.9.3 RC3 — новый интерфейс и управление с геймпада

Тестовая версия для Windows 10/11 x64.

- Обновлён интерфейс: тёмные панели, бирюзовые акценты, компактная навигация в заголовке, адаптивная галерея и отдельные разделы настроек. Исправлено прямоугольное выделение внутри скруглённых кнопок.
- Сочетание геймпада сохраняет replay одним нажатием, без обязательного удержания. Другие зажатые игровые кнопки не мешают. Одно нажатие создаёт один клип; перед следующим нужно отпустить кнопки сочетания.
- Ограничение «только в активной игре» для геймпада отделено от клавиатуры и по умолчанию выключено. Сохранение привязки больше не зависит от обработчика клавиатуры.
- В настройках показываются распознанные кнопки. Если сочетание распознано, но сохранение недоступно, приложение объясняет причину.
- Сохранены исправления непрерывности аудио из RC2, плавная регулировка громкости и обновление существующей установки с сохранением клипов и настроек.

## Установка и обновление

Скачайте **CLIPALKA-Setup.exe** и запустите поверх предыдущей версии. Перед обновлением завершите запись. Если CLIPALKA работает в трее, установщик предложит её закрыть. При выборе папки используйте прежнюю папку установки.

**CLIPALKA-win-x64.zip** — вариант без установки. Для обновления установленной программы используйте Setup. Контрольные суммы находятся в **SHA256SUMS.txt**.

## Проверка геймпада

Включите replay, откройте «Настройки → Клавиатура и геймпад», выберите контроллер, назначьте сочетание и сохраните настройки. Нажмите сочетание один раз. Строка «Ввод с контроллера» помогает проверить, какие кнопки читает Windows.

Автоматические проверки включают 67 тестов, обучение и восстановление привязки контроллера, короткое нажатие с другими игровыми кнопками, отсутствие дублей и повторное подключение. Также проверяются модуль аудио, экспорт replay, интерфейс и обновление/удаление приложения.

Реальные DualSense/Flydigi по Bluetooth и SteelSeries Sonar требуют проверки на ваших компьютерах: среда автоматической сборки работает без этих устройств.
