# CLIPALKA 0.9.3 RC2 — Студия

Новая тестовая версия для Windows x64.

- Дизайн «Студия»: верхние вкладки, широкий предпросмотр последнего клипа, крупные кнопки записи, replay и микрофона. Настройки разделены на видео, аудио, клавиатуру и геймпад.
- Исправлен дефект микшера: короткие аудиоблоки микрофона больше не дополняются нулями на каждом стыке. Сохранена плавная регулировка громкости.
- Добавлены дополнительные способы обнаружения контроллеров Windows для DualSense и Flydigi, обновление списка и сведения о подключении.
- Установщик обновляет существующую установку. Записи и настройки сохраняются; удаление доступно через Windows и ярлык «Удалить CLIPALKA».

## Установка

Скачайте **CLIPALKA-Setup.exe** и запустите поверх предыдущей версии. Перед обновлением завершите текущую запись. Если CLIPALKA работает в трее, установщик предложит её закрыть. Выберите прежнюю папку, если он предложит выбор.

**CLIPALKA-win-x64.zip** — вариант без установки. Контрольные суммы файлов находятся в **SHA256SUMS.txt**.

## Проверка

Пройдены 66 тестов, проверка непрерывности PCM, загрузка исправленного аудиомодуля, экспорт replay, отрисовка интерфейса и обновление/удаление приложения.

Для Sonar и Bluetooth-геймпадов нужна повторная проверка на ваших устройствах: среда автоматической сборки работает без них.
