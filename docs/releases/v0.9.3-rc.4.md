# CLIPALKA 0.9.3 RC4 — Signal и DualSense Bluetooth

Предварительный релиз для Windows 10/11 x64.

- Новый интерфейс Signal: угольный фон, фиолетовый акцент, крупное превью последнего
  клипа, компактные вкладки, адаптивные кнопки и галерея.
- DualSense Bluetooth читается напрямую через Windows Raw Input. Добавлен разбор
  полных Bluetooth-пакетов с проверкой CRC32. Пользователь подтвердил назначение
  сочетания и сохранение реального клипа с этим источником.
- Живой индикатор выбранного микрофона учитывает громкость и mute. Дополнительный
  мониторинг останавливается при скрытом окне и уходе с главной; звук не сохраняется
  и не воспроизводится этим индикатором.
- В «Настройки → Видео и файлы» появился запуск вместе с Windows после входа
  пользователя. Переключатель применяется общей кнопкой сохранения.
- Компактное меню трея в стиле приложения: статус, иконки, актуальные хоткеи,
  команда остановки записи и отключение недоступных действий.
- Сохранены исправленный PCM-микшер, настройки, клипы и обновление существующей
  установки. Добавлены проверки автозапуска и его обработки установщиком.

## Обновление

Завершите текущую запись и запустите **CLIPALKA-Setup.exe** поверх предыдущей
установки. Используйте прежнюю папку; отдельная вторая установка не требуется.
Клипы и пользовательские настройки сохраняются.

Для DualSense выберите **«DualSense · Raw Input»** в «Настройки → Клавиатура
и геймпад», заново назначьте сочетание и сохраните настройки. Привязка к прежнему
Desktop HID не заменяется автоматически, чтобы не перепутать кнопки источников.

**CLIPALKA-win-x64.zip** — portable-вариант. Если переносите его папку, заново
сохраните включённый автозапуск из нового расположения. Для обновления установленной
программы используйте Setup. SHA-256 файлов приведены в **SHA256SUMS.txt**.

## Проверки и ограничения

75 тестов основной логики, включая формат пакетов DualSense и отказ при повреждённом
CRC. Проверки WPF, команд трея, службы контроллера, нативного аудиомодуля,
экспорта replay, автозапуска и обновления/удаления выполняются отдельно.

DualSense Bluetooth проверен на компьютере пользователя. Flydigi и другие модели
требуют аппаратной проверки. Индикатор микрофона проверен на доступность выбранного
Sonar-устройства, mute и восстановление мониторинга; при проверке была тишина,
поэтому реакция на физическую речь и качество Sonar-записи требуют отдельной оценки.
