# CLIPALKA — проверка на Windows

Перед публикацией релиза выполните эти проверки на Windows 10 22H2 и Windows 11.

## Базовая запись

- [ ] Приложение запускается без прав администратора.
- [ ] В списке видны все подключённые экраны.
- [ ] Запись 30, 60 и 120 FPS создаёт воспроизводимый MP4.
- [ ] Во время полноэкранной игры изображение продолжает записываться.
- [ ] Остановка записи корректно завершает файл даже после 30+ минут.
- [ ] Указанная пользователем папка создаётся и используется.

## Звук и SteelSeries Sonar

- [ ] Выбрать `SteelSeries Sonar - Gaming` как вывод.
- [ ] Запустить игру и голосовой канал Discord одновременно.
- [ ] Проверить, что в MP4 слышны игра и Discord.
- [ ] Выбрать `SteelSeries Sonar - Microphone` как ввод.
- [ ] Проверить, что голос слышен и синхронен с видео.
- [ ] Нажать mute во время записи: системный звук остаётся, микрофон замолкает.
- [ ] Снова включить микрофон: голос возвращается без перезапуска записи.
- [ ] Повторить проверку с обычными наушниками и обычным микрофоном.

> Важно: CLIPALKA записывает полный микс выбранного устройства вывода через WASAPI
> loopback. Чтобы одновременно захватить разные виртуальные каналы Sonar (например,
> Game и Chat), в SteelSeries GG направьте их в один выбранный playback endpoint либо
> выберите общий Sonar Stream/Mix endpoint, если он доступен в вашей конфигурации.

## Replay и хоткеи

- [ ] После запуска дождаться минимум 35 секунд и сохранить replay.
- [ ] Файл содержит только последние примерно 30 секунд, включая оба аудиоисточника.
- [ ] Повторное сохранение replay работает без перезапуска приложения.
- [ ] Во время сохранения replay игра продолжает попадать в кольцевой буфер без заметного разрыва.
- [ ] После 10+ минут работы временные replay-файлы ротируются и не растут бесконечно.
- [ ] После появления игры replay переключается с выбранного монитора на окно игры.
- [ ] В боковой панели отображается `Игра: Rocket League` до сохранения replay.
- [ ] После `Win`/Alt+Tab и открытия Telegram replay не показывает Telegram — источником остаётся игра.
- [ ] Три последовательных replay из одной игры не содержат чёрный экран или окна с другого монитора.
- [ ] При 120 FPS быстрые повороты камеры не дают разрывов или крупных блоков изображения.
- [ ] При одновременном звуке игры и микрофона нет треска или цифрового клиппинга.
- [ ] `Ctrl+Shift+R` начинает и завершает запись из игры.
- [ ] `Ctrl+Shift+Z` сохраняет replay из игры.
- [ ] `Shift+Z`, одиночная `Z`, стрелки, Delete и мультимедийные клавиши можно назначить хоткеями.
- [ ] `Shift+Z` работает в CLIPALKA, даже если такое сочетание также назначено в другой программе.
- [ ] Названия всех назначенных клавиш отображаются на английском.
- [ ] Escape очищает поле и полностью отключает хоткей.
- [ ] После выхода из игры ввод текста не запускает replay при включённой защите хоткеев.
- [ ] Клик по полю хоткея и нажатие сочетания заполняет его без ручного ввода.
- [ ] Обычная запись из активной игры выбирает её окно, а при отсутствии распознанной игры — монитор.
- [ ] Имя файла содержит название игры/активного приложения и дату.
- [ ] Пустое поле полностью отключает соответствующий хоткей.
- [ ] Конфликтующий системный хоткей показывает понятную ошибку.

## Трей и уведомления

- [ ] Значок CLIPALKA виден в системном трее и использует фирменную иконку.
- [ ] Сворачивание и кнопка закрытия прячут окно в трей, не останавливая replay.
- [ ] Двойной клик по значку возвращает окно.
- [ ] Меню трея открывает приложение, управляет записью/replay и полностью завершает процесс.
- [ ] При старте записи, её остановке, сохранении replay и mute микрофона появляется игровой оверлей.
- [ ] Во время обычной записи сверху отображается компактный `REC`-таймер.
- [ ] Оверлей и `REC`-таймер не перехватывают мышь и не попадают в готовое видео/replay.
- [ ] Оверлей появляется на мониторе с активной игрой и скрывается примерно через три секунды.

## Отказы и восстановление

- [ ] Отключение микрофона во время ожидания не приводит к падению приложения.
- [ ] После смены устройства настройки сохраняются между запусками.
- [ ] После перезапуска SteelSeries Sonar устаревший endpoint автоматически заменяется доступным и replay запускается без ошибки AudioManager.
- [ ] При недоступной папке показывается ошибка и приложение остаётся открытым.
- [ ] Команда «Выйти» из трея во время записи корректно финализирует MP4.

## Проверка 0.9.3 RC1

- Установить новую сборку поверх прежней через Setup: используется та же папка,
  в списке программ остаётся одна CLIPALKA. Клип и настройки должны сохраниться.
- В папке приложения работает ярлык «Удалить CLIPALKA». После удаления клипы,
  диагностика и `%LOCALAPPDATA%\CLIPALKA\settings.json` остаются на месте.
- Проверить обновление при работающей в трее CLIPALKA: завершить запись и закрыть
  приложение по запросу установщика; принудительного прерывания записи нет.

- DualSense по Bluetooth: выбрать устройство в «Настройки → Replay с контроллера»,
  назначить сочетание, сохранить. Короткое нажатие: один клип и уведомление.
  Повторить с другой зажатой игровой кнопкой. Поле «Ввод с контроллера» показывает
  реально прочитанные кнопки; недоступное сохранение объясняется уведомлением.
- Flydigi: повторить в XInput и DirectInput, если они доступны у конкретной модели.
  После смены режима заново выбрать устройство и назначить сочетание.
- Подключить контроллер с уже зажатым сочетанием: клип не создаётся до полного
  отпускания и нового нажатия. Проверить повторное Bluetooth-подключение, краткое
  нажатие, удержание и выход из игры при включённой защите геймпада «только в игре».
  Защита клавиатуры не должна блокировать геймпад. Выключенный replay не создаёт
  файл и показывает причину после распознанного сочетания.
- В режиме назначения сам replay не срабатывает. По истечении 15 секунд без ввода
  назначение отменяется. При отключении контроллера запись экрана продолжает работать.

- На главной, в галерее и настройках доступна общая кнопка сохранения. Изменения
  FPS/устройств не применяются к записи до сохранения. Остановка записи работает
  даже при невалидных несохранённых полях.
- Shift+X переключает микрофон, Ctrl+G открывает галерею из трея. Совпадающие
  сочетания не сохраняются. Escape отключает хоткей; ввод в поле не запускает действие.
- Галерея находит клип по названию, превью открывает системный плеер, «Показать
  в папке» выделяет нужный файл. При отсутствии клипов нет изображения случайной игры.
- Запись показывает таймер и квадрат остановки, mute подписан «Выключен».
- Выключенный replay имеет серый статус и кнопку включения. Ошибка запуска
  не блокирует повторное включение и работу остальных страниц.
- Двойное нажатие хоткея во время экспорта не создаёт очередь одинаковых клипов.
- На реальном replay проверить разрешение/FPS и звук, особенно при 120 FPS,
  переходе через границу сегментов, Alt+Tab и игре с устройствами Sonar.
