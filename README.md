# CLIPALKA

CLIPALKA — компактное Windows-приложение для записи экрана и сохранения последних
30 секунд. Оно одновременно пишет изображение выбранного монитора, системный звук
с выбранного устройства вывода и голос с выбранного микрофона.

## Что уже есть в MVP

- обычная запись экрана в MP4 (H.264);
- сохранение последних 30 секунд;
- системный звук + микрофон в одной записи;
- выбор монитора, устройства вывода и устройства ввода;
- поддержка виртуальных Windows-устройств, включая SteelSeries Sonar;
- 30, 60 или 120 FPS;
- выбор папки сохранения;
- mute/unmute микрофона прямо во время записи;
- глобальные переназначаемые хоткеи: одиночные клавиши и сочетания вводятся нажатием,
  а их названия всегда отображаются на английском;
- неэксклюзивное отслеживание клавиатуры позволяет использовать сочетания вроде
  `Shift+Z`, даже если другое приложение уже зарегистрировало такой хоткей;
- режим «хоткеи только в игре» защищает от случайного replay при обычной печати;
- replay автоматически привязывается к активному окну игры и не показывает Telegram или другие окна поверх неё;
- до обнаружения игры и после её закрытия используется выбранный монитор;
- обычная запись берёт активную игру, а если она не распознана — выбранный монитор;
- системные уведомления о начале/окончании записи и сохранении replay;
- игровые оверлей-уведомления и постоянный компактный REC-таймер, которые не попадают в захват;
- работа из системного трея с быстрыми командами записи, replay и выхода;
- фирменная иконка приложения, ярлыка и установщика;
- цельный игровой интерфейс с одной боковой навигацией, большой карточкой текущей
  игры, быстрыми действиями, лентой клипов и компактной колонкой настроек;
- реальные миниатюры, длительность и время четырёх последних MP4 в ленте клипов;
- отдельная регулировка громкости системного звука и микрофона;
- автоматическая замена устаревшего ID аудиоустройства после перезапуска SteelSeries Sonar;
- индикатор текущего источника replay: игра или монитор;
- имена файлов вида `Название игры Replay - 2026-09-22 18-42-10.mp4`;
- H.264 High Profile, unconstrained VBR до 100 Мбит/с при 120 FPS и stereo 192 kbps;
- запас громкости при смешивании игры и микрофона для снижения клиппинга;
- сохранение настроек в `%LOCALAPPDATA%\CLIPALKA\settings.json`;
- аппаратное кодирование, когда оно поддерживается системой.

## Установка

1. Откройте страницу **Releases** этого репозитория.
2. Скачайте `CLIPALKA-Setup.exe`.
3. Запустите установщик и затем CLIPALKA из меню «Пуск».

До появления первого опубликованного релиза приложение можно собрать вручную.

## Сборка для разработчика

Требуется Windows 10/11 x64, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
и Visual C++ 2015–2022 Redistributable x64.

```powershell
dotnet restore CLIPALKA.sln
dotnet test CLIPALKA.sln -c Release
dotnet publish src/Clipalka.App/Clipalka.App.csproj -c Release -r win-x64 --self-contained true -o publish/win-x64
```

Для сборки установщика установите Inno Setup 6 и откройте
`installer/CLIPALKA.iss`.

## SteelSeries Sonar и Discord

CLIPALKA использует Windows WASAPI loopback. Это означает, что она записывает весь
звук, который проходит через выбранное устройство вывода. Если игра и Discord
направлены в разные виртуальные каналы Sonar, выберите в SteelSeries GG общий
Stream/Mix endpoint либо направьте нужные приложения в один playback endpoint.
Микрофон выбирается отдельно, например `SteelSeries Sonar - Microphone`.

## Как работает replay

В фоне работает ограниченный кольцевой MP4-буфер. Сначала источником служит выбранный монитор; когда CLIPALKA
обнаруживает активную игру, буфер переключается на её окно и сохраняет эту привязку даже
при Alt+Tab или открытии Telegram. По команде файл
снимается безопасный snapshot фрагментированного MP4, а сам захват продолжает работать.
Windows Media Foundation быстро собирает из последних сегментов нужные 30 секунд без
повторного запуска основного буфера. Сегменты автоматически ротируются и удаляются,
поэтому временный файл больше не растёт бесконечно.

## Ограничения MVP

- защищённый DRM-контент Windows может не отдавать в loopback;
- некоторые игры с эксклюзивным полноэкранным режимом или античитом требуют отдельной
  проверки; права администратора CLIPALKA сама не запрашивает;
- одновременный захват разных Sonar Game/Chat endpoints как отдельных дорожек пока не
  реализован — записывается выбранный итоговый output mix;
- изменение экрана, FPS или аудиоустройства применяется к следующей записи/replay-сессии;
- сейчас видео содержит одну смешанную аудиодорожку; раздельные дорожки — будущая функция.

Полный сценарий ручной проверки находится в
[`docs/WINDOWS_TEST_CHECKLIST.md`](docs/WINDOWS_TEST_CHECKLIST.md).

## Архитектура

- `Clipalka.Core` — настройки, хоткеи и безопасные пути;
- `Clipalka.App` — WPF-интерфейс, Windows-хоткеи, устройства и движок записи;
- `ScreenRecorderLib` — Windows Graphics Capture, WASAPI и Media Foundation;
- `Windows.Media.Editing` — обрезка replay без поставки FFmpeg;
- `Clipalka.Core.Tests` — кроссплатформенные тесты бизнес-логики.

## Публикация релиза

### Проверочная сборка 0.9.2 RC1

- Убрано принудительное `ForceMono` для всех микрофонов: сохраняется сигнал устройства,
  который библиотека приводит к выходному формату stereo 48 kHz.
- Запуск считается успешным после первого записанного кадра, а не после вызова API.
  При смене replay-сессии старая остаётся активной, пока новая не выдаст первый кадр.
  На ожидание отведено 8 секунд; неудачная новая сессия освобождается.
- Ошибки фонового захвата отражаются в статусе. Завершение пытается освободить
  все сессии даже при ошибке одной из них.
- Это **не подтверждённое исправление** всех звуковых артефактов и пропусков кадров.
  Нужна повторная проверка с реальной игрой и устройствами Sonar на Windows.

В разделе **«Запись» → «Проверка записи и звука»** доступна добровольная диагностика:

1. Сохраните нужные настройки, выберите устройства и нажмите «Начать проверку».
2. После подтверждения переключитесь в игру, играйте и говорите около минуты.
3. Сохраните replay привычным хоткеем до истечения 90 секунд.
4. Дождитесь автоматического завершения или нажмите «Остановить проверку».
5. «Открыть папку проверки» откроет `Diagnostics` рядом с обычными клипами.

Диагностика запускает свежий replay-буфер и сохраняет исходные сегменты MP4,
экспортированный replay, PCM WAV микрофона и системы до смешивания, общий WAV
до AAC и журнал времени callback-ов. Голос сохраняется **после внутреннего
преобразования/громкости SRL**, это не независимая запись исходного Sonar.
Содержимое может включать личные разговоры, экран, имена окон и пути файлов —
проверьте папку перед отправкой. Ничего не загружается автоматически.

Нужно не менее 3 ГБ свободного места. Ограничитель проверяет состояние раз в секунду
и останавливает replay примерно через 90 секунд, при достижении 2 ГБ или остатке
диска менее 512 МБ. Завершение экспорта/кодирования может занять дополнительное
время и место. Диагностические файлы автоматически не удаляются; их можно удалить
после разбора. После проверки replay остаётся выключенным: для возобновления
сохраните настройки с включённым replay или перезапустите приложение.

Запись диагностических WAV выполняется через ограниченную очередь вне callbacks;
потери этой очереди отмечаются в `writer-summary.json`. Накладные расходы диагностики
ненулевые: это сбор доказательств, а не эталонный замер производительности.
Время frame-callback — Unix milliseconds; оно не равно PTS в MP4 и не доказывает,
что картинка каждого кадра отличается. Для этого анализируются сами MP4.

GitHub Actions проверяет проект при каждом push и pull request. Тег вида `v0.9.1`
дополнительно создаёт self-contained сборку и установщик, затем прикладывает их к
GitHub Release.

```powershell
git tag v0.9.1
git push origin v0.9.1
```

Каждая Windows-сборка также создаёт артефакт `CLIPALKA-ui-preview`: изображения
настоящего WPF-интерфейса в размерах 1585×992 и 1280×800. Они используют тестовые
названия устройств и клипов, не запускают запись и не заменяют ручную проверку
игрового захвата. Локально на Windows: `CLIPALKA.exe --render-ui <папка>`.

В версии 0.9.1 исправлены отступы шаблона кнопок, светлая системная подсветка
списков, высота кнопки replay и расположение подписей. Компоновка масштабируется
в небольших окнах, сохраняя пропорции основного экрана.
